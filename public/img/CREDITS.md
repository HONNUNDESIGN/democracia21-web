# Créditos de fotografía

Fotografía propia del cliente (Democracia 21 / Alberto Jaén). Ya no hay imágenes de stock (Unsplash) en este directorio — el cliente subió sus fotos reales y se eliminaron todos los placeholders anteriores.

| Archivo | Contenido |
|---|---|
| `hero-claim.webp` | Fondo del hero (claim "Dēmos × Krátos") y poster del vídeo: Miriam González Durántez en un mitin/charla, chaqueta amarilla, fondo púrpura "España mejo…". |
| `miriam-01.webp` | Foto de Miriam González Durántez para la sección "La que da la cara" — retrato informal con portátil. |
| `tee-demoskratos.webp` | Camiseta — "dēmos + kratos" (etiquetas "pueblo" / "poder"). |
| `tee-siglo21.webp` | Camiseta — checkboxes "☐ Derecha ☐ Izquierda ☒ Siglo 21". |
| `gorra-21.webp` | Gorra — díptico "MUY 21" / "Versión 21". |
| `sudadera-siglo21.webp` | Sudadera — "siglo 21". |
| `hoodie-noestarde.webp` | Sudadera con capucha — "No es tarde." |
| `tote-transparencia.webp` | Tote bag transparente — "Transparencia y sin letra pequeña". |
| `chapa-escuchar.webp` | Chapa — "Escuchar antes de hablar". |
| `museo-pareja.webp` | Foto de la pareja de espaldas (mochila marrón, chaqueta vaquera, pelo rizado pelirrojo) para el statement de Museo.astro. |

Originales comprimidos con `sips` (JPEG, calidad ~80) y luego convertidos a WebP con `cwebp -q 80 -m 6` (JPEGs) / `cwebp -q 82 -m 6 -alpha_q 90` (PNG con transparencia) desde los originales subidos por el cliente, para minimizar peso sin pérdida visible. Los originales .jpg/.png ya no están en el repo.
